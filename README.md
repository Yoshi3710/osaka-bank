# こども銀行探検隊｜大阪信用金庫 花博公園支店（企画・試作版）

「恐竜アイランド」のQR探索方式を、子ども向け金融教育イベントの題材に置き換えた試作です。

## URL
- 参加者用： https://yoshi3710.github.io/osaka-bank/
- 運営・QR印刷用： https://yoshi3710.github.io/osaka-bank/qrmaker/

※ GitHub Pages の公開設定を有効にするまでは、上記URLを開けない場合があります。

## 参加方法
1. 受付に置いた **START** のQRをスマートフォン標準カメラで読み、参加者用サイトを開きます。
2. 地図上の6つのマークをタップすると、ミッションのヒントが表示されます。
3. 会場に置いた6種類のQRは **参加者ページ内の「QRを読み取る」** ボタンから読みます。標準カメラを使ってページを移動しません。
4. QRごとに1問の金融クイズと学習解説があります。誤答時も解説を読んで先に進めます。
5. クリアするたびに地図の1区画が開き、全6区画で金庫が現れます。金庫をタップすると認定証が表示されます。

## セキュリティ・運営上の注意
- 本アプリは氏名・学校名・電話番号・口座番号・暗証番号を収集しません。
- 進行状況はブラウザの `localStorage` とCookieにのみ保持します。サーバーには送信しません。
- マップ・キャラクターは新規作成したSVGです。**大阪信用金庫の公式ロゴ・実店舗写真は未使用です**。支店の承認・素材提供後に差し替える方針です。
- カメラ利用にはHTTPSが必要です。Safari/Chromeの通常ブラウザモードを推奨します。
- QRデコードはスキャン開始時に外部の固定バージョン `jsQR 1.4.0` を必要に応じて取得します。ネットワークなしでのQRスキャンは保証しません。
- 共用端末の場合は、参加者が交代する前にブラウザのサイトデータを消去してください。
- 試作の認定証は端末内の進行で表示されるもので、サーバー側の本人確認や景品引換済み管理はありません。景品の二重引換防止は受付側で管理してください。
- 運営用 `?test` の疑似読取パネルは公開ページでは無効です（localhostでのみ有効）。
- 会場配置・通路安全・画像や名称の利用については支店の確認を受けてから正式運用してください。

## 公開方法
GitHub のリポジトリ `Yoshi3710/osaka-bank` の **Settings → Pages** で、**Build and deployment → Deploy from a branch → main / (root) → Save** を指定してください。ファイルが公開されるまで反映時間が必要です。

## 元のシステムとの関係
元：`Yoshi3710/dinosaur01` と `Yoshi3710/qrmaker01`。保持した基本機能：アプリ内QRスキャン、進行の自動保存・再開、6区画の地図解放、重複取得防止、最終報酬、運営用QRの一括・個別印刷。
変更した機能：恐竜の題材と地図を銀行テーマに置換、スキャン後にクイズと学習説明を追加、宝箱・鍵を金庫・認定証に変更、QRの識別子を専用化。

## 検証
GitHubにアップしたHTML/JSの構文検証、7つのQR文字列一致、元のQRとの混同防止、QRスキャンの保留→クイズ→取得状態保存、重複防止、6件完成、認定証の解放、進行の再読込を自動チェック。印刷QRマトリクスは生成時にQRデコーダで文字列を検証済み。
**実機カメラ、iPhone Safari/Android Chromeでの撮影・表示、印刷実機、および公開URL経由の動作は未検証です。**
